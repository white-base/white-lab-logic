Logic 시작하기 ​

적용 기준 engine 1.x · 2026.10.22원본 문서 ↗

Logic은 Node.js 생태계에서 DB 모듈과 UI 모듈을 조합해 시스템을 만드는 플랫폼입니다. 데이터 모델과 화면 구현을 독립적인 패키지로 관리하고, 필요한 기능을 계약으로 연결합니다.

무엇을 조립하나요? ​

  • DB 모듈은 데이터 스키마와 업무 기능의 단위입니다.
  • DB 번들은 함께 쓰는 DB 모듈을 하나의 구성으로 묶습니다.
  • UI 모듈은 화면과 실행 환경을 제공하고 계약을 구현합니다.
  • UI 번들은 DB와 UI를 선택하고 연결하는 조립의 진입점이 됩니다.

모듈을 더하면 기능뿐 아니라 채워야 할 계약도 늘어날 수 있습니다. 구조를 먼저 이해한 뒤 요구와 제공을 함께 확인하세요.
