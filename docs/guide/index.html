조립 가이드 ​

적용 기준 engine 1.x · 2026.10.22원본 문서 ↗

조립은 모듈 선택 → 관계 선언 → 계약 확인 → 검증의 순서로 진행합니다. 먼저 데이터 책임과 교체할 UI 책임을 구분하세요.

기본 흐름 ​

  1. 모듈 조회에서 DB/UI 모듈·번들을 찾습니다.
  2. 빠지면 조립이 깨지는 관계는 depend로 선언합니다.
  3. 선택하거나 교체할 조합은 include로 선언합니다.
  4. expect/provide 계약의 scope·owner·수량을 확인합니다.
  5. logic validate와 logic check로 선언·조립 결과를 나눠 검사합니다.
  6. logic tree --contract 또는 logic gui로 관계를 살펴봅니다.

카탈로그와 로컬 결과 ​

카탈로그는 등록된 선언과 정적 의존 정보를 제공합니다. 사용처별 exclude·교체·동적 setup이 반영된 실효 결과는 로컬 조립에서 확인합니다. 같은 계약 이름이 검색되어도 연결 성공을 뜻하지 않습니다.
